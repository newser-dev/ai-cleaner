# AI 공백 제거기

AI 생성 텍스트에 숨은 보이지 않는 문자(제로폭 공백, NBSP, 스마트 따옴표 등)를 찾아 제거하는 단일 페이지 사이트. 정적 파일 하나로 동작.

배포·애드센스 절차는 `../daily-calc/README.md`와 동일:
도메인 구매 → 정적 호스팅 배포 → robots.txt/sitemap.xml의 `YOUR-DOMAIN.com` 치환 → 서치콘솔 등록 → 애드센스 신청(head 주석 자리에 스크립트, 루트에 ads.txt) → 승인 후 `.ad-slot`에 광고 단위 삽입.

단일 페이지라 애드센스 승인이 어려울 수 있음 — 승인용으로 관련 글 페이지(예: "AI 글 티 안 나게 다듬는 법", "유니코드 공백 종류 정리") 몇 개를 추가하는 것을 권장.
